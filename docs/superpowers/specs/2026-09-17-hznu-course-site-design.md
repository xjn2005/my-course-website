# 杭州师范大学个人课程网站设计

## 目标

将现有课程模板的 Astro 版本改为个人课程索引。首页列出多门课程；每门课程拥有独立的课程页及可维护的 Schedule。首门示例课程为“实变函数（2026 Fall）”。

## 页面与导航

- 首页是极简课程清单。每项只显示课程名、学期和对应教师。
- 每门课程是一个独立的 Astro 子站，所有课程页使用 700px 内容宽度：课程主页、Schedule、Materials 和 Assignments。
- 所有课程页共用同一个课程页头：返回课程列表、课程名、学期、教师和课程内导航；当前页以暗红色下划线标识，切换页面时不改变这一层级。
- 课程主页显示课程简介；移除独立 Lectures 页面。
- Materials 是教材、参考书和补充资料的独立页；Assignments 是按课程筛选的作业清单，并可进入每次作业的详情页。

## Schedule

每门课程的 Schedule 固定为五列：`Date`、`Topic`、`Slides`、`Notes`、`Video`。

- 普通课次采用白色与暖白色交替行；Topic 可有课次编号、加粗标题和多行说明（如阅读或作业）。
- Slides、Notes、Video 为可选链接；仅在提供链接时渲染与参考图相同语义的红色 PDF、文档和视频图标，避免空占位。
- 停课或节假日使用横跨全表的浅红提示行，不引入绿色。
- 样式参考用户提供的 CMU 15-445 Schedule：强表头分隔线、紧凑文本层级与资源图标列；站点保持白底、深色正文和暗红链接/图标的单一配色系统。

## 内容与实现

- 使用 Astro 内容数据，定义课程的标题、学期、教师、简介、Materials 和按课程归属的课程条目。
- 作业使用独立 Astro 内容集合，含课程标识、发布日期、标题、可选 PDF/附件/答案和 Markdown 正文；课程的 Assignments 页面只查询本课程的作业。
- 课程条目包含日期、标题、可选说明、可选 Slides / Notes / Video 链接，或停课提示。
- 页面按日期排序课程条目并渲染统一表格；没有任何资源链接时不生成资源图标。
- 字体不依赖外部加载：正文优先使用 Source Han Serif / Noto Serif CJK 的中文衬线字回退，标题与导航优先使用 Source Han Sans / Noto Sans / 系统中文无衬线字，以强化课程资料的阅读层级。
- 删除仅服务于旧 Jekyll Lecture / 事件模型的 Astro 页面与组件，保留新的通用布局和所需静态资源。
- Astro 生产构建通过后，删除原 Jekyll 源码、Gemfile 和示例课程内容；项目只保留 Astro 作为唯一站点实现。

## 校验

- 运行 Astro 的生产构建，验证内容集合、路由和样式可编译。
- 以首门示例课程验证普通课次、缺失资源链接、停课行、Materials 和作业详情五种渲染情况。

## 非目标

- 不增加 CMS、数据库或新的前端依赖。
