# 杭州师范大学个人课程网站设计

## 目标

将现有课程模板的 Astro 版本改为个人课程索引。首页列出多门课程；每门课程拥有独立的课程页及可维护的 Schedule。首门示例课程为“实变函数（2026 Fall）”。

## 页面与导航

- 首页是极简课程清单。每项只显示课程名、学期和对应教师。
- 课程页为窄正文栏的文档式排版，提供返回课程列表的链接、课程标题和 Schedule。
- 移除 Lectures 导航、页面和内容集合。课程页不需要原模板的作业、考试或公告模块。

## Schedule

每门课程的 Schedule 固定为五列：`Date`、`Topic`、`Slides`、`Notes`、`Video`。

- 普通课次采用浅灰交替行；Topic 可有课次编号、加粗标题和多行说明（如阅读或作业）。
- Slides、Notes、Video 为可选链接；仅在提供链接时渲染相应图标，避免空占位。
- 停课或节假日使用横跨全表的浅绿色提示行。
- 样式参考用户提供的 CMU 15-445 Schedule：强表头分隔线、紧凑文本层级与资源图标列。

## 内容与实现

- 使用 Astro 内容数据，定义课程的标题、学期、教师和描述，以及按课程归属的课程条目。
- 课程条目包含日期、标题、可选说明、可选 Slides / Notes / Video 链接，或停课提示。
- 页面按日期排序课程条目并渲染统一表格；没有任何资源链接时不生成资源图标。
- 删除仅服务于旧 Jekyll Lecture / 事件模型的 Astro 页面与组件，保留通用布局和静态资源。

## 校验

- 运行 Astro 的生产构建，验证内容集合、路由和样式可编译。
- 以首门示例课程验证普通课次、缺失资源链接和停课行三种渲染情况。

## 非目标

- 不迁移或修改现有 Jekyll 版本。
- 不增加 CMS、数据库或新的前端依赖。
