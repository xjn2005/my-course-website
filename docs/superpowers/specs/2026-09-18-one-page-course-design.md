# 单页课程信息设计

## 目标

- 每门课程只保留一个可阅读页面，纵向依次展示课程介绍、Schedule、Materials 和 Assignments。
- 移除课程标题下的顶部导航，不再显示「课程主页」、Schedule、Materials、Assignments 链接。
- 课程日程改为适合国内课程的课次列表：显示课程模块/主题、课程类型与资料或作业信息，而非仅显示日期、节次、形式。

## 页面与路由

课程根路径 `courses/[slug]/` 是唯一内容页面。它保留课程标题、学期、任课教师和课程介绍，并按以下顺序直接渲染三个区块：

1. `Schedule`：按课次列出教学主题，可显示颜色标签、阅读材料和作业链接。
2. `Materials`：渲染课程 Markdown 正文，作为补充资料的唯一编辑入口。
3. `Assignments`：显示该课程的作业列表。

现有 `/schedule`、`/materials`、`/assignments` 路径保留为兼容入口，并重定向至课程根路径对应的锚点；页面中不再提供任何顶部跳转链接。

## 数据与组件

课程 frontmatter 的 `schedule` 由当前的日期与节次字段扩展为可选的课次、模块、主题、资料和作业字段。`Schedule.astro` 根据这些字段渲染紧凑的课次列表；没有额外信息的课程仍可使用原有日期/节次数据，避免一次性重写所有课程内容。

课程正文继续由 Astro Markdown 渲染。作业继续复用 assignments collection 及现有作业详情页，不新增数据源或依赖。

## 样式与可访问性

三个区块使用明确的二级标题和稳定的锚点。模块标签使用文本与颜色共同传达含义，不只依赖颜色。移动端保持单列可滚动阅读。

## 异常与验证

- 没有日程、资料或作业时，对应区块显示简短的空状态，不留下空白区域。
- 运行 `npm run build`，确认全部课程与旧路径均可生成。
- 检查一个课程页面：没有顶部课程导航，且能从上到下看到 Schedule、Materials、Assignments。
