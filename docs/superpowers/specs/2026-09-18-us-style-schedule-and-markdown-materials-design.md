# 美国大学式日程与 Markdown Materials

## 目标

- Schedule 按实际日期列出每次课，不显示“第 1–16 周”。
- 每门课的教学材料和主题由课程 Markdown 正文维护。

## 设计

课程 frontmatter 中的每个固定上课时段保留首课日期、节次、形式和 16 次课。日程组件从这些数据生成连续的每周日期，并按日期显示。每一行只有日期、上课和形式；课程主题不在结构化日程中维护。

课程 Markdown 正文从课程主页移至 Materials 页面渲染。用户可直接在 frontmatter 后使用标准 Markdown（标题、链接、列表、代码块或按日期记录课程主题）。旧的 `materials` 列表字段及其页面列表渲染移除，避免两个材料入口。

## 验证

运行 `npm run build`，确认内容 schema 与全部静态课程页面均可构建。
